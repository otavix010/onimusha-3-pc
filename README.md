# Onimusha 3: Demon Siege — port nativo para PC

> **Projeto de fãs, sem fins lucrativos.** *Onimusha* é marca registrada da Capcom; este projeto não tem relação com a Capcom. Este repositório **não contém o jogo**: você vai precisar da **sua própria cópia** do DVD (a versão europeia, **SLES-51914**).

Port nativo para PC por **recompilação estática** com o [PS2Recomp](https://github.com/ran-j/PS2Recomp), no mesmo esquema dos outros ports de PlayStation 2 do Otavix: o seu PC gera e compila o jogo a partir da sua ISO.

## Estado atual: em desenvolvimento

**O port ainda vai começar.** Antes, estamos fortalecendo a base comum dos ports de PS2 (tradutor, runtime, IOP, VU1 e GS) com os primeiros jogos: [Spawn: Armageddon](https://github.com/otavix010/spawn-armageddon-pc), [Ghost Rider](https://github.com/otavix010/ghost-rider-pc), [Medal of Honor: European Assault](https://github.com/otavix010/moh-european-assault-pc) e [10.000 Bullets](https://github.com/otavix010/10000-bullets-pc). As novidades vão aparecendo em `NOVIDADES.md` e na página do jogo no Otavix Launcher.

## O que você vai precisar

- A ISO da versão europeia: Redump **"Onimusha 3 (Europe, Australia) (En,Fr,De,Es,It)"** (SLES-51914).
- Windows 10/11 de 64 bits, um processador com AVX2 e espaço para a geração (alguns GB).

A **native PC port** of *Onimusha 3: Demon Siege* (PlayStation 2, 2004) by **static recompilation** with [PS2Recomp](https://github.com/ran-j/PS2Recomp). **Work in progress: the port has not started yet** — we are first strengthening the shared PS2 base with the first four games.
